# Letter PDF download and browser printing

Use **Download Letter PDF** above the geographic map when the saved file must be Letter landscape (792 × 612 PDF points) or Letter portrait (612 × 792 points). The chosen orientation is written into the PDF page's MediaBox. It does not depend on CSS @page support or the browser print dialog. The generated snapshot has one page, the current outlined area/appearance/labels, north/scale when present on the prepared map, and the same attribution. The map fits proportionally within 8 mm margins and a measured footer, using space previously reserved for browser chrome. Geographic extent is retained; the PDF physical map size/scale can differ from native print. Scale bars enlarge with the map and the generated topo numeric scale is recomputed for actual-size output.

The browser's **Print this map** action still opens native printing synchronously. Its page size is a CSS request; browser/platform/printer settings can override it. A 2026-10-14 iOS sample displayed the selected landscape map on an actual portrait Letter page. Do not call native landscape device acceptance complete from Chromium's preferCSSPageSize PDFs. If orientation is wrong in native printing, use the explicit PDF, open it in a PDF viewer and print at actual size. The file fixes page geometry; printer settings can still scale or rotate output.

PDF download rasterizes the prepared map and attribution at 200 dpi and embeds one lossless grayscale or RGB image. Street paths/text remain vectors in native print/SVG export, while the exact-page PDF is an image with no selectable text or vector editing. Raster topo source detail is not increased by placing it on a 200 dpi page. PDF has a white background and retains B&W pixels/color as selected. No lesson pack is required.

The async download path is separate from native printing. It freezes SVG and tile placement from the prepared snapshot, fits the available page, bounds image decode time, clips to the selected map extent, wraps attribution within margins and rejects overflow. It neither fetches elevation/source data nor changes the selected view. A generated snapshot link remains available if the browser does not automatically download; generate a new PDF after changing the map.

The bounded image-page encoder uses browser Canvas support and optional native CompressionStream and fixed PDF syntax, not a general PDF import/parser library. It emits byte-counted streams, cross-reference offsets, a catalog/page tree and one image/content stream per page. No user-controlled strings enter PDF syntax; map text is rendered as pixels. Image payload is capped at 20 MiB and dimensions at 4000 pixels. The normal 200 dpi Letter canvas is 2200 × 1700 or 1700 × 2200 pixels (about 15 MB RGBA before encoding).

CSP adds blob: to img-src only, so self-generated SVG snapshots can be decoded to canvas. Script/connect/object rules are unchanged. Temporary SVG URLs are revoked on success/error; replacing a generated PDF revokes the prior PDF URL. Map imagery uses the existing anonymous-CORS loaded tiles. No runtime dependency is added.

Validation covers exact portrait/landscape MediaBoxes, byte-correct xref entries and input limits, plus browser downloads from street and topo snapshots under host-header and Pages-meta CSP. The download test deliberately overrides native landscape CSS with portrait and still requires a landscape PDF. Downloaded files must contain a page image and nontrivial decoded image samples; render and inspect them independently to verify visibility and attribution. Actual iOS download/open/print and physical scale checks remain device acceptance gates.

## B&W fidelity follow-up

B&W downloads now embed exact 8-bit grayscale samples; color uses exact RGB samples. Native `CompressionStream('deflate')` produces a zlib-wrapped stream for PDF FlateDecode. If compression is unavailable, fails or does not reduce size, the encoder uses uncompressed samples. Neither path adds JPEG quantization. Original source tiles can already contain JPEG artifacts. Page geometry, 8 mm margins and native vector street printing are unchanged. Lossless files may be larger; the fallback is about 3.7 MB grayscale or 11.2 MB RGB for a Letter page, within the 20 MiB limit.

Topo B&W output defaults to **Stronger lines**, with **Standard grayscale** available in Topo print contrast. This deepens midtones without spatial sharpening or a black/white threshold. See [measured quality checks and limits](print-quality.md). The user accepted the previous physical page fit; this new contrast/encoding still needs an actual paper comparison. Earlier counts above are historical execution records.


## Lesson PDF download

**Download lesson PDF** under Lesson map and print saves the selected Map only, Learner worksheet or Instructor guide. It uses the validated fixed-scale paper model without fit-to-page resizing: a 20 m bar at 1:1,000 occupies 20 mm between tick centers. Each page has an explicit Letter portrait or landscape MediaBox and no browser-generated URL/date footer. Printer/viewer scaling remains outside the file; choose actual size / 100% and measure the printed bar.

Lesson maps and literal teaching/source text use lossless 300 dpi grayscale pages (2550 × 3300 or 3300 × 2550). The first page retains the map model's 10 mm margins and declared scale; long map titles/credits that do not fit are rejected rather than shrinking the map. Worksheets and guides add separately paginated question/answer/source pages. Learner annotations omit the target answer, instructor annotations include it. Text paragraphs, explicit newlines and long unbroken source URLs wrap within physical margins; answer space is reserved for handwriting. Native print keeps its existing vector output. Downloaded PDF text is rasterized and cannot be selected/searched; this matches the simple image-based geographic exporter, with higher resolution for lesson linework.

The map SVG's computed presentation attributes and all teaching blocks are frozen before asynchronous decode/compression. A print-view change invalidates prepared links and suppresses a pending stale result. Failed generation is retryable, and a visible Save prepared lesson PDF link supports browsers that do not automatically save. Export does not change the active exercise, scoring or learner records. No runtime dependency, source fetch or remote PDF service is added.

The shared encoder retains single-page geographic output and adds bounded page trees: at most 64 pages, 20 MiB per image, 64 MiB total image payload and 4000 pixels per dimension. Lesson text pagination also enforces the 64-page limit. Lossless compression falls back to raw grayscale samples where unavailable. Device memory and printer acceptance remain separate gates.
