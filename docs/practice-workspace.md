# Practicing with a lesson map

Choose **Practice**, then **Load street basics** and **Begin lesson session**, or open a saved session under **Saved sessions and backups**. **Choose or change a lesson** offers other prepared packs and import; it closes after loading in Practice. Practice while stationary. Browsing a geographic area does not create a reviewed lesson for that place.

The current question appears above the practice workspace. On a wide screen the map and answer controls sit beside each other; on a narrow screen the map, any profile chart and answer controls form one stack. Map instructions remain below the map. Source credits stay visible below the workspace, followed by saved sessions and backups.

## Locating a point

Read the prompt and the visible references, then tap/click the map. **?** marks your tentative answer. Tap again to replace it, or choose **Reset draft answer** to clear it. Select **Submit answer** when ready. The tentative marker does not reveal the answer key.

For a keyboard alternative, use **Map reference**. Each reference lists its connected roads; search if the list is long. Choosing a reference places the same tentative point as selecting it on the map. All references are offered without consulting the endpoint answer.

For a point between references, choose **Focus map to place a point**. Arrow keys move a cursor in screen directions; hold Shift for smaller steps and press Enter to place your answer. The position message describes distance and geographic direction from the nearest reference. Rotation changes which screen direction represents north; the N arrow shows geographic north. Tab leaves the map. Advanced coordinate entry is also available.

Small synthetic maps show their authored short node names on screen and paper. These are map clues, not additional junctions: two crossing roads connect only where the source topology connects them. A real-source pack still needs authored, reviewed clues; raw source IDs are not automatically added to its map.

## Connecting and detouring

Route and detour questions set their start and travel mode automatically. **Start** identifies the task start and **End** the destination; on a named reference they appear together, for example Start A. Spelling these out keeps a reference named E distinct from the destination. A cross and dashed line identify an authored exercise-only closure, not a real road condition. The same clues appear on the learner worksheet.

Tap a connected road to extend the draft route, or choose **Next directed edge** and **Add edge**. If a road has multiple possible outgoing edges, use the list to choose its direction. Remove the last edge or clear the trace to revise it. Submit the answer to check the route; unknown access and unresolved restrictions still require review.

Every new question starts with a fresh trace, even when the previous route could answer it. **Retry exercise** retains the current trace so you can edit it; **Reset draft answer** clears it. Traces and unfinished endpoint placements stay in memory and are not restored from a session backup. Submitted attempts remain recorded.

## Progress and pausing

The progress line shows how many questions have a submitted answer and how many latest answers are correct. Repeated attempts count once toward coverage. **All questions answered** does not mean all answers are correct or establish mastery. Ended sessions retain a per-question coverage review and all submitted history. Independent path review is in **Review/edit materials**, below the shared map; it is separate from submitted answers. Older saved records marked completed internally use the same derived coverage; the raw lifecycle remains available in Session record details.

Use **Pause session** to continue later. It clears unfinished points/traces but retains submitted answers and hints in this view. Check the save status before closing and keep a backup if saving is unavailable. Resume in this view, or open the in-progress saved session after reloading. Reload/backup restore opens the last committed answer; an unfinished retry is discarded. **End session** closes that record permanently. An early end is labeled Ended early; begin a separate session to practice again. Saved-session choices use lesson names, coverage and local dates; exact IDs remain in details/backups.

## Printing the question you are answering

Beginning or opening an active session selects learner output and follows the current question. **Print current question** prints that question; the caption states the audience, Letter orientation and page count. Choose instructor output explicitly when you need answer criteria, and print it separately. Print audience never reveals an answer key on the practice map.

Changing **Question to print** makes an explicit manual override. Re-enable **Follow current practice question** or choose **Print current question** to return to the active task. Map-only output remains available. A PDF filename identifies the pack revision, question, audience and orientation.


## Tasks and settings

**Explore and print** browses real geography without changing the loaded lesson or submitted progress. **Practice** keeps the current question, map and answer controls together. **Review/edit materials** reveals independent path tracing, feature inspection and label editing below the same prepared map. Switching these tasks preserves drafts in this view; it does not pause/end a session. Native Back/Forward, task links and keyboard skip links work across these sections. Save warnings and relevant retry/conflict actions remain visible outside collapsed sections and across tasks.

Open **Map view, print output and saved preferences** for rotation, labels, output audience, the current-question print action, PDFs and saved view settings. These tools are expanded in Review. Letter orientation is currently shared by both map contexts and labeled **all outputs**; loading a pack may apply its paper defaults. Separating those settings remains Plan 10 package D work.

Begin is unavailable while a replacement pack is being read/validated; a failed load retains the previous map and reports the error. Switching to another task does not make a pending load a successful one.

Street basics covers orienting, locating, connecting and detouring. Terrain examples follow contours (including depressions as a variant), relative slope, then landforms/profiles. The on-screen evidence names technical validation and author review separately from independent curriculum approval. An imported schema review flag does not supply independent approval; source-backed drafts remain drafts. Existing scoring gates are unchanged.
